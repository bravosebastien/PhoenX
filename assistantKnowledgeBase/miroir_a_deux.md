# Le Miroir à Deux

Le **Miroir à Deux** (anciennement appelé Le Pacte) est un espace de complicité entre deux Créateurs vivants qui partagent des souvenirs communs.

## Le principe des versions croisées
Le Miroir permet à deux personnes d'écrire chacune leur propre version d'un même événement.
- Chacun écrit son récit de son côté.
- Le contenu de l'autre reste scellé tant que les deux n'ont pas terminé leur rédaction.
- Une fois que les deux voix sont prêtes, le Miroir se révèle et les deux récits deviennent lisibles par les deux participants.

## Verrouillage de la révélation
Tant que l'un des deux partenaires n'a pas validé sa version (bouton "J'ai terminé ma version"), personne ne peut voir ce que l'autre a écrit. Cela garantit l'authenticité de chaque témoignage sans influence extérieure.

## Double consentement pour le Livre de Vie
Pour que ces souvenirs croisés puissent enrichir le **Livre de Vie** (IA Biographe), les deux participants doivent donner leur accord explicite :
- Chaque participant dispose d'un interrupteur "Nourrir mon Livre de Vie" dans le détail du Miroir.
- Si un seul participant dit "Oui", le souvenir reste privé entre les deux.
- Ce n'est que si **les deux** disent "Oui" que l'IA pourra utiliser ces récits pour la rédaction du Livre.

## Comment lancer un Miroir ?
1. Va dans ta **Bibliothèque** depuis l'écran d'accueil.
2. Appuie sur l'icône **"Le Miroir à Deux"** (deux mains qui se serrent).
3. Utilise le bouton **"+"** pour inviter un proche à se refléter avec toi.
4. Partage-lui le lien d'invitation généré.
