Mon Quiz vous permet de créer un petit jeu sur vous-même, que vos proches pourront jouer pour voir s'ils vous connaissent bien. Pour chaque question, vous choisissez soit une réponse tapée librement (qui sera comparée à la vôtre), soit plusieurs choix parmi lesquels il faudra deviner le bon — dans ce cas, le bouton "Magie IA" peut générer pour vous des fausses réponses crédibles, pour rendre le jeu plus vivant sans que vous ayez à tout inventer vous-même. Vous pouvez ajouter, pour chaque question, un petit message taquin de votre composition qui s'affichera si la personne se trompe. Vous pouvez tester votre propre quiz avant de le rendre disponible à vos Destinataires.
